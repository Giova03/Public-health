# ADR-005 — PWA offline-first, IndexedDB en trois zones, clinique append-only

- **Statut** : ACCEPTÉ (arbitrage du porteur, phases 3–4)
- **Date** : 2026-09

## Contexte

Les CSPS vivent avec un réseau intermittent ; mentir sur l'état en ligne coûte des vies. Les conflits de synchronisation sont le risque n°1.

## Décision

PWA (manifeste + service worker), IndexedDB en trois zones : outbox (opérations à remonter, opId idempotent), mirror (données de référence téléchargées), meta (curseurs, filigranes). Les données cliniques sont append-only — une erreur se contre-annule, ne se réécrit jamais (garde SQL V3). Trois régimes de conflit : clinique = sans conflit, métadonnées = dernier écrit gagne, identité = jamais fusionnée automatiquement.

## Conséquences

L'appareil reste utile sans réseau ; la montée est idempotente. Coût : discipline append-only stricte et protocole /sync/batch complet en épique E2.
