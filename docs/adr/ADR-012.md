# ADR-012 — Icônes : Lucide pour l'interface, simple-icons pour les marques

- **Statut** : ACCEPTÉ (arbitrage du porteur, phases 3–4)
- **Date** : 2026-09

## Contexte

L'interface a besoin d'icônes d'action cohérentes ; la documentation a besoin de logos de marques (Spring, PostgreSQL, Vercel…) sans risque de licence.

## Décision

Lucide pour toute icône d'action UI (ensemble cohérent, maintenu). simple-icons pour les logos de marques uniquement — bibliothèque CC0-1.0 clonée en local, livraison des SVG dans apps/pwa/public/brands/.

## Conséquences

Zéro risque de licence, un seul langage visuel. Contrepartie : veiller à ne jamais déformer un logo de marque (usage descriptif).
