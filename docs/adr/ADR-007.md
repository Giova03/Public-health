# ADR-007 — Stack : Java 21 LTS / Spring Boot 3 / Next.js 16 / Supabase

- **Statut** : ACCEPTÉ (arbitrage du porteur, phases 3–4)
- **Date** : 2026-09

## Contexte

Écosystème mature, talents disponibles à Ouagadougou, coûts de démarrage quasi nuls, reversibilité maximale.

## Décision

API : Java 21 LTS + Spring Boot 3 (JPA en lecture, Flyway en écriture du schéma, virtual threads). Front : Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui. Hébergement géré : Supabase (PostgreSQL + Auth, région UE). Brevo pour les notifications, PostHog et Sentry pour l'observabilité — données NON sensibles uniquement, jamais de donnée clinique dans les analytics.

## Conséquences

Démarrage rapide et gratuit, montée en charge progressive. Contrepartie : dépendance aux offres gratuites (supervision des quotas en E8).
