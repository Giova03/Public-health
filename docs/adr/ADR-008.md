# ADR-008 — Connecteur PH HUB sortant uniquement

- **Statut** : ACCEPTÉ (arbitrage du porteur, phases 3–4)
- **Date** : 2026-09

## Contexte

Le HUB mutualise les services des partenaires ; l'exposition d'entrées multiplie la surface d'attaque et les dépendances réseau.

## Décision

Le connecteur hub n'émet QUE des appels HTTPS sortants (443) : file locale chiffrée, retrait avec trempe et gigue, enveloppe signée HMAC-SHA256 avec numéro de séquence et filigrane, détection de trous, file morte (DLQ). Le partenaire reste maître de son périmètre.

## Conséquences

Aucune entrée à défendre, résilience aux coupures. Coût : complexité du mode différé et supervision des files (observabilité E8).
