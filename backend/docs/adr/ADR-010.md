# ADR-010 — Vercel + Render + Docker partout (sans Cloudflare)

- **Statut** : ACCEPTÉ (arbitrage du porteur, phases 3–4)
- **Date** : 2026-09

## Contexte

Le porteur refuse Cloudflare par prudence sur les coûts long terme. La protection de périmètre classique doit être compensée.

## Décision

Vercel (PWA) et Render (API, runtime Docker) apportent TLS, DDoS de base et en-têtes de sécurité. Le durcissement applicatif porte le reste : Bucket4j (limitation de débit), validation d'entrée, RLS, audit. Toute l'API est conteneurisée (Dockerfile fourni) : l'auto-hébergement D4 reste possible sans réécriture ; un ajout ultérieur de couche CDN ne demanderait qu'un changement DNS.

## Conséquences

Aucune dépendance hard à un CDN ; factures prévisibles. Contrepartie : la sécurité applicative doit être irréprochable (revue ASVS L2 en E5).
