# ADR-004 — UUID v7 générés côté client

- **Statut** : ACCEPTÉ (arbitrage du porteur, phases 3–4)
- **Date** : 2026-09

## Contexte

Les consultations démarrent hors ligne ; l'attribution d'identifiants par le serveur exigerait un aller-retour réseau impossible.

## Décision

Toute entité créable hors ligne porte un UUID v7 (RFC 9562) généré par le client : ordonné dans le temps, index B-tree compact, uniques sans coordination.

## Conséquences

La synchronisation n'a plus de conflit de clé par construction. Contrepartie : les identifiants ne prédisent rien sur le contenu (l'audit reste la source de vérité).
