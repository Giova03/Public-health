# ADR-011 — Défense en profondeur sans CDN

- **Statut** : ACCEPTÉ (arbitrage du porteur, phases 3–4)
- **Date** : 2026-09

## Contexte

Sans Cloudflare, chaque plan de défense doit tenir seul : l'attaque peut venir du réseau OU de l'application OU de la base.

## Décision

Quatre plans : (1) Accès — TLS Vercel/Render, en-têtes stricts (HSTS, nosniff, frame deny), limites de taille ; (2) Application — authN JWT, RBAC × ABAC, validation Bean, limitation Bucket4j ; (3) Données — Row Level Security pilotée par les variables de session app.* (V5), la base refuse en dernier recours ; (4) Audit — journal append-only six dimensions, chaînage par hachage, break-the-glass tracé.

## Conséquences

Une faille d'un plan ne suffit pas à exposer les données. Coût : RLS complète à finir (épique E5) et posture de sécurité documentée en continu.
